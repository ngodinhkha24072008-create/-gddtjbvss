Using it on your phone

  1. Open this controller in Chrome on Android from its web address (it needs https). Bluetooth can't be used inside the claude.ai preview.
  2. HM-10 / BLE module: tap Connect BLE and pick the module.
  3. HC-05 / HC-06: pair it in Android Bluetooth settings first (PIN is usually 1234), then tap Connect HC-05. Needs a recent Chrome.
  4. The Arduino side is RobotCarArm.ino at 9600 baud. No code changes are needed.
